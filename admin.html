Spelling lists

For grown-ups. Whatever you save here shows up on Alina's and Monty's game within a minute or two.

One-time setup: this page needs a GitHub token so it can save the lists. It stays in this browser only.

  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → spell.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Set the longest expiry allowed, create it, and paste it below.
